EECS 110, Fall 2025

“I really enjoy how this class specifically breaks down what each line of code is doing. Madelyn makes sure to explain the code in terms of what Python is thinking when it is reading it, and I find this to be very helpful. Also, this class is doing a great job at showing us the basics of Python while still showing us what people really do with computer science.”

Midterm evaluation

“I very much enjoyed this course. It showed me that I am definitely much more interested in coding, and I want to explore other computer science classes here at Michigan. End-of-term evaluation
